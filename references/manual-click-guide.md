# 手动兜底：Buddy加油站五步点击法（Shadow 总结）

> 当自动脚本失效或环境不支持时，用 cua-mcp 的 MCP 工具手动完成签到。
> 来源：Shadow（Mac Pro 节点），2026-09-24。

## Step 1 · 拿窗口坐标

```
computer_action { action: "get_windows" }
```

取 `owner: "Electron"`、`title: "WorkBuddy"` 那条，记下 `bounds`：

```json
{"X": 2560, "Y": 25, "Width": 1920, "Height": 975}
```

- 这是 **macOS 全局桌面坐标**（多显示器时 X 会 > 主屏宽度，别以为是错的）。
- 每台机器、每次挪窗口都不同，**必须每次重取，不要硬编码**。

## Step 2 · 整窗截图，找卡片

```
screenshot { x: X, y: Y, width: W, height: H, return_base64: false }
```

目标 = **侧栏左下角的 Buddy加油站卡片**，形如：

```
        ⌒ 100 ⌒
      每日可领通用积分
   已领 8 天 | 累计领取 800 分
   Buddy加油站·9期      9/29结束
   [ 立即领取 ]  [ 体验高校专家 ]
```

按钮文案判据：
- `立即领取`（深色/实心）= 今天还没领
- `今日已领`（灰色/禁用）= 已领过，**别再点**（幂等，安全）

## Step 3 · 区域放大，精确算按钮中心

对卡片那一小块再截一次（比整窗清晰得多）：

```
screenshot { x: 卡片左上X, y: 卡片左上Y, width: 320, height: 250, return_base64: false }
```

返回图就是该区域 **1:1**。在图上量按钮中心的像素偏移，换算：

```
屏幕坐标 = 区域左上 + 图内偏移
```

> 这一步别省。整窗图缩放过，直接目测误差能到 ±50px，容易点到隔壁「体验高校专家」（间距不到 40px）。

## Step 4 · 点击

```
computer_action { action: "mouse_click", x: 屏幕X, y: 屏幕Y, button: "left", clicks: 1 }
```

## Step 5 · 截图复核（必做，不许跳过）

再截同一区域，成功判据（三项同时成立）：
- 按钮文案 `立即领取` → `今日已领`
- `已领 8 天` → `已领 9 天`
- `累计领取 800 分` → `累计领取 900 分`

> "没验证就报成功 = 撒谎"。截图前后对比是唯一的证据链。

## 要点与坑

1. 坐标是全局桌面坐标，多屏拼接时不从 0 开始。
2. 截图区域参数是全局坐标，不是窗口相对坐标。
3. 区域截图 1:1，整窗截图有缩放——算点击点一律用区域截图。
4. 点完必须复核，文案 + 数字双判据。
5. 窗口被遮挡/最小化时点击可能落空 → 先确认 `get_windows` 里 `onscreen: true`。
6. 别点错的邻居按钮：「体验高校专家」就在右边，间距不到 40px。
7. 签到天数影响连续奖励，`今日已领` 就别重复点。

## 最短可执行清单（复制即用）

```
1. computer_action  get_windows                              → 记 X,Y,W,H
2. screenshot       {x:X, y:Y, width:W, height:H}            → 看卡片按钮文案
   若已显示「今日已领」→ 收工
3. screenshot       {x:卡片左上, width:320, height:250}       → 量「立即领取」中心 → 得 (px, py)
4. computer_action  mouse_click {x:px, y:py}                 → 点击
5. screenshot       同区域                                     → 复核：按钮灰色「今日已领」+ 天数/累计各 +1
```
